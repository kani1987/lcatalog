# 订单管理系统 - HTML5后台管理模板

这是一套专门为订单系统设计的HTML5后台管理模板，具有高密度数据展示和现代化的用户界面。

## 功能特性

### 📊 订单列表页面
- **高密度数据展示**：优化表格布局，在有限空间内展示更多订单信息
- **智能筛选**：支持按状态、日期范围、金额范围筛选订单
- **实时搜索**：全局搜索订单号、客户姓名、商品名称、电话号码
- **表格排序**：点击表头可对各列进行升序/降序排序
- **批量操作**：支持全选/反选，便于批量处理订单
- **分页功能**：每页显示20条记录，支持页码跳转

### ✏️ 订单编辑页面
- **表单验证**：完整的前端表单验证
- **自动计算**：实时计算商品小计和订单总额
- **多商品支持**：可添加/删除多个商品项
- **订单号生成**：自动生成唯一订单编号
- **状态管理**：支持订单状态流转

### 📱 响应式设计
- **移动端适配**：完美支持手机和平板设备
- **侧边栏折叠**：小屏幕下侧边栏自动隐藏
- **表格横滚**：移动端表格支持横向滚动
- **紧凑布局**：移动端优化的紧凑显示

### 💡 用户体验
- **现代化UI**：采用现代设计语言，界面简洁美观
- **状态标识**：不同颜色标识订单状态，一目了然
- **工具提示**：鼠标悬停显示完整信息
- **加载动画**：优雅的加载状态提示

## 技术栈

- **HTML5**：语义化标签，良好的可访问性
- **CSS3**：Flexbox布局，CSS Grid，动画效果
- **Vanilla JavaScript**：原生JS，无框架依赖
- **Font Awesome**：图标库
- **响应式设计**：支持各种屏幕尺寸

## 数据结构

### 订单数据格式
```javascript
{
    id: 1,                                    // 订单ID
    orderNumber: 'ORD-2024-001',             // 订单号
    customerName: '张三',                     // 客户姓名
    customerPhone: '13812345678',            // 联系电话
    customerAddress: '北京市朝阳区...',        // 收货地址
    productName: 'iPhone 15 Pro',           // 商品名称
    productPrice: 8999.00,                   // 单价
    quantity: 1,                             // 数量
    totalAmount: 8999.00,                    // 总金额
    status: 'pending',                       // 订单状态
    orderDate: '2024-01-15 10:30:00',       // 下单时间
    notes: '客户要求尽快发货'                  // 备注
}
```

### 订单状态说明
- `pending`: 待处理 (黄色标签)
- `processing`: 处理中 (蓝色标签)
- `shipped`: 已发货 (绿色标签)
- `delivered`: 已送达 (深绿色标签)
- `cancelled`: 已取消 (红色标签)

## 使用方法

1. **直接打开**：双击 `index.html` 文件即可在浏览器中运行
2. **本地服务器**：推荐使用本地服务器运行以获得最佳体验

### 本地服务器运行示例
```bash
# 使用Python内置服务器
python -m http.server 8000

# 使用Node.js http-server
npx http-server

# 然后在浏览器访问 http://localhost:8000
```

## 定制说明

### 修改样式
- 主要颜色变量在 `css/style.css` 顶部定义
- 表格密度可通过修改 `padding` 和 `font-size` 调整
- 响应式断点可在媒体查询中修改

### 数据对接
- 模拟数据在 `js/script.js` 的 `mockOrders` 数组中
- 可替换为真实API调用
- 支持RESTful API接口对接

### 功能扩展
- 可添加更多筛选条件
- 支持导出Excel功能
- 可集成图表统计
- 支持订单状态流转
